# Frontend - Task Manager

A simple task management web application built using React + Vite, styled with Tailwind CSS.

The app allows users to:
* View a list of tasks
* Create new tasks

## Tech Stack

* React + Vite
* Tailwind CSS
* JavaScript
* React Hooks
* axios

## Installation & Setup Instructions
**Step 1:** Clone the repository
* *Open your terminal*
* *git clone https://github.com/vijay-ram01/MoJ_FE.git*
* *cd MoJ_FE*

**Step 2:** Install dependencies
* *npm install*

**Step 3:** Start the FE development server
* *npm run dev*

The application will be availabe at **http://localhost:5173/**

( *Make sure to setup the backend and database aswell. Follow the instructions at* **https://github.com/vijay-ram01/MoJ_BE** )
